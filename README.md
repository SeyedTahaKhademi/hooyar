## 🇮🇷 معرفی به فارسی (Persian)

**هویار** یک دستیار هوشمند و خودمختار برای برنامه‌نویسان است که به صورت مستقیم روی سیستم‌عامل ویندوز اجرا می‌شود. این ابزار با بهره‌گیری از قدرت مدل‌های زبانی بزرگ (LLMs)، به شما در نوشتن کد، مدیریت فایل‌ها و اجرای دستورات ترمینال کمک می‌کند.

### ✨ قابلیت‌های کلیدی
- **مدیریت هوشمند فایل‌ها:** خواندن، نوشتن و ویرایش مستقیم فایل‌های پروژه.
- **ترمینال داخلی:** اجرای دستورات Shell و PowerShell به صورت خودکار.
- **پشتیبانی از مدل‌های متنوع:** اتصال به Gemini، OpenAI، Claude، DeepSeek، Groq و حتی مدل‌های محلی (Ollama).
- **نصب‌کننده Wizard:** دارای فایل نصب حرفه‌ای برای ویندوز.
- **رابط کاربری مدرن:** طراحی زیبا با پشتیبانی کامل از زبان فارسی و فونت وزیرمتن.
- **تایید خودکار (Auto-Approve):** امکان اجرای خودکار ابزارها برای سرعت بخشیدن به توسعه.

### 🚀 نحوه استفاده
1. آخرین نسخه را از بخش [Releases](https://github.com/seyedtahakhademi/hooyar/releases) دانلود و نصب کنید.
2. کلید API ارائه‌دهنده مورد نظر خود را در تنظیمات وارد کنید.
3. پوشه پروژه خود را انتخاب کرده و شروع به چت با هویار کنید!

## 🇬🇧 English Introduction

**Hooyar** is an elite autonomous AI Coding Agent built for Windows. It empowers developers by integrating advanced LLMs directly with their local workspace, enabling seamless code generation, file manipulation, and terminal execution.

### ✨ Key Features
- **Smart File System:** Direct access to read, write, and modify files within your workspace.
- **Integrated Terminal:** Automatically executes Shell/PowerShell commands.
- **Multi-Provider Support:** Connect to Gemini, OpenAI, Claude, DeepSeek, Groq, and local models (Ollama).
- **Professional Installer:** Comes with a user-friendly NSIS Wizard installer.
- **Modern UI:** Sleek design with full RTL support and high-performance terminal view.
- **Auto-Approve Mode:** Speed up your workflow by letting the agent execute tools automatically.

### 🚀 How to Use
1. Download the latest `.exe` from the [Releases](https://github.com/seyedtahakhademi/hooyar/releases) section.
2. Enter your API Key in the Settings modal.
3. Select your workspace folder and start building!

## 🛠️ Development & Build (برای توسعه‌دهندگان)

If you want to run the project locally or build it yourself:
اگر می‌خواهید پروژه را به صورت محلی اجرا کنید یا خودتان بیلد بگیرید:

```bash
# Install dependencies
npm install

# Run in development mode
npm run electron:dev

# Build the Wizard Installer (.exe)
npm run dist
```
